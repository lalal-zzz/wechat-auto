## 固化的执行规则

- 先观察底层页面、独立弹窗、右侧内容标签；每个窗口分别识别，不能只截主窗。
- 同进程校验绑定 HWND；句柄消失或属于其他进程立即拒绝。
- 固定点档案按微信版本、**完整窗口截图尺寸**、DPI、主题选择；坐标经 ScreenToClient
  转为消息目标的客户区坐标。当前 `LayoutProfile.client_width/client_height` 字段承载该截图尺寸。
- OCR 定位的文字控件和 CV 定位的叉号来自当前截图，唯一匹配才交给 BasicSkill。
- 右侧标签栏属于嵌入的 Chrome_WidgetWin_0；正文可拥有 Chrome_RenderWidgetHostHWND。
  由现有 KeyboardOnlyDriver 枚举子 HWND 并用 WM_* 路由，未创建第二套驱动。
- 关闭一个嵌入标签使用 close_content_tab；不得对主 HWND 发 WM_CLOSE。
- 编辑框使用取消，菜单使用已登记的 dismiss，独立内容窗口使用 close。
- 点击发出不代表完成。后置条件失败返回 success=false、automatic_retry=false。
- 单个标签的关闭目前要求一个可识别标题及唯一叉号；多标签不能盲猜活动标签。
- 网络搜索不按 Enter 选择未知联系人。先核对完整查询，再点击精确网络建议。
- 每个页面的操作与确认动作清单由 actions.page_capabilities 返回；确认动作不能经
  通用页面执行器发送或保存。actions.plan_page_route 是声明路径，执行时仍逐步验证。

## 后续验收

1. **多标签**：活动/非活动标签、切换、逐个关闭、关闭后剩余标签标题、返回上级、
   页面加载/错误/无结果；保存每步前后图，不能只比较页面名称。
2. **右侧内容类型**：公众号列表/文章、视频号详情/直播、小程序；区分聊天旁的右栏、
   替换中央内容的页面和独立窗口；测试打开、返回、关闭、聊天草稿保留。
3. **群页**：稳定 @chatroom 身份、群成员、群资料、公告只读窗口；群身份不能从昵称推断。
4. **媒体与工具面板**：表情、图片/视频查看、文件预览、收藏、聊天记录检索、引用和右键菜单。
5. **资料场景**：从聊天头像进入的浮动资料卡、无公开微信号、权限限制、标签编辑；
   备注/权限等实际修改另走逐次确认测试。
6. **环境组合**：浅色、其他 DPI/窗口尺寸、不同 4.x 版本、最大化/恢复、独立窗口与遮挡。
7. **窗口生命周期**：设置等窗口的 WM_CLOSE、句柄复用、弹窗阻断、切换中截图失败、OCR 失败。
8. **持续回归**：公共控件脱敏样例与私有原图本地回放分别记录；没有实机证据不标 verified。
