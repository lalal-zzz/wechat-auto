# 当前截图决定控件位置

0.8.1；页面动作协议 4。旧的按版本/尺寸/DPI/主题加载比例坐标档案已移除。
BasicLayout、LayoutProfile、KeyboardOnlyLayout 及相关配置不再存在；不读取旧本机坐标档案。窗口变大、变小或内部栏宽变化后必须重新观察。

```text
当前 HWND 截图
  → OpenCV：当前侧栏边界、公共图标、分隔线、搜索框、输入框、关闭叉号
  → OCR：文字控件、搜索分区、可见微信号精确核验
  → 唯一候选与当前窗口/页面校验
  → BasicSkill → 同一个 KeyboardOnlyDriver → WM_* 消息
  → 新截图核验后置状态
```

图标模板只有公共控件的二值形状，不包含位置、窗口尺寸、头像或私人文字。
当前侧栏在截图中通过长边界识别，多尺度模板匹配输出当前像素框、分数和窗口坐标。
选中/未选中图标先转轮廓剪影比较，红色提示点不参与图标匹配。不存在或多个空间
候选会停止，不能点第一个或使用昨天的坐标。比例只用于把本帧像素点传给 HWND。

已实现导航识别：聊天、通讯录、发现、主菜单。文字按钮使用当前 OCR 精确唯一匹配；
右侧关闭仍由当前叉号 CV 产生坐标。联系人更多、聊天详情、表情等尚无当前帧检测器
的控件明确返回未实现。旧固定行号选人、旧语义坐标修改、表情格子坐标发送已拒绝；
身份/表情语义数据继续保留。输入区焦点从当前识别的唯一聊天 composer 产生。
