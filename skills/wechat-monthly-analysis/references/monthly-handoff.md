# 分片/月度交接

只保存于本地 data/work/analysis/{run_id}/，不是第二套正式 Memory。

- stable scope：conversation_id、月份、self/contact 稳定身份与发送方向映射。
- frozen input：来源/版本/hash、首尾稳定消息引用、条数与可读字符数。
- model：用户指定的阅读模型、实际分配的连续月份/分片；输入记录与正文引用分别计数，evidence_ids覆盖整月输入，引用子集不冒充阅读覆盖。
- reading：每块实际语义阅读范围、边界引用/未完回合、未读文本与媒体缺口。
- reading integrity：Windows 输出明确用 UTF-8；不能将控制台乱码误报为源损坏。长消息、卡片/引用文字不得静默截短或只取前几项，包含链接的自然语言不能整段过滤。统一使用 `python scripts/read_analysis_block.py SOURCE --start 1 --count 600 --compact --fold-media` 显示正文；长文本按实际输出量减块。不得新建平行渲染器直接打印 `readable` 或 `content`；如需本地捕获，只调用同一安全读取函数。XML 解析失败用同一读取器加 `--recover-xml`、按原序号单独展开；本地已有可选 lxml 时安全恢复白名单自然文本，仍保留原解析缺口记录。缺少依赖或恢复失败保留缺口，不能回退为打印原字段；不另写平行恢复脚本。输出工具截断或乱码的块撤销覆盖并补读；取到行数、脚本结束或UTF-8文件存在不能证明模型实际读懂。
- media XML：`readable` 也可能是原始媒体 XML，须与 `content` 一样只抽取可见自然文字；不显示密钥、CDN、XML属性或其他技术载荷。纯媒体标未解读，不以原始XML成功输出证明媒体解读。解析器禁止外部实体和联网加载；补读只使用授权本地内容。
- monthly candidates：按月独立正文路径；月内多片合并与边界去重情况。
- dimensions：事项/任务、双方事实/偏好/习惯/行为/情绪/价值观/边界、约定表达、双方各自社会关系、变化及反例；未出现与未检查分开。
- ownership：speaker、actor、fact_owner、relation_owner、mentioned_or_quoted；关系双方、scoped reference、有效期与短证据引用。
- continuity：开放事件、已有阶段、跨月衔接依据、重复发生与转述区分。
- independent review：复核 Agent、展开的原回合、归属错误与修订、通过/缺口；未复核候选不能交接为成功输入。
- efficient review：每月默认一次集中审核、整批反馈、一次修订；修改后只核改动和受影响结论。优先主体/第三方归属、关键日期、关系变化、冲突边界与实际结果；普通日常不逐条防守性复核。实质串月或系统性错归才扩大范围，不因低影响措辞或元数据美化重复整篇流程。
- useful prose：同一事实只集中详述一次，保留具体偏好、行为线索、关系和冲突过程。来源/媒体/unknown局限末尾集中说明，不每段重复免责声明；未出现维度不填满unknown模板。笔记只记新事实、短锚点和未完回合，寒暄/重复日常合并。全文阅读不减少。
- citation support：逐命题核附带的确切序号与短原句，少量精确锚点替代长无关引用列表；源中别处存在相似事实不证明该引用有效。每个重要日期、第三方归属、边界/关系、决定/实际结果与推断都须查其实际支持回合，不能仅用几组抽样就宣称全部核心命题已复核。
- cross-period isolation：同一 Agent 阅读本月、复核别月时，来源和笔记以 conversation_id/period/source_hash 明确分隔。每条核心命题写出本月实际读取的精确短原句与方向后再归纳，不能从复核任务的记忆搬入事实或把别月序号换成当前月份。发现串月污染时撤回候选，对整篇命题重新展开当前月原文核验；只删除被发现的一段不足以恢复可信状态。
- quantities and actions：具体数量、生日/日期、出口/路线、款项、完成结果必须回查明确原句，不能从工作笔记或记忆补数字。相邻问句不直接证明后来回答的事实，未转写语音不支持内容/边界结论；unknown作者不分配个人owner。复核找不到支持就删除/限缩或标未知，不能保留“看起来合理”的细节。
- compact reading：读取器可加 `--compact`，以短数组替代重复字段名、直接显示北京时间；完整正文不缩短。块大小仍按实际输出量设置，任何工具截断都要补读，紧凑格式不等于抽样。源时间与计划/回顾日期含义分别核对。
- media folding：可用 `--compact --fold-media` 合并连续且类型明确、没有可读文字/解析错误的纯媒体占位符，保留序号范围、起止时间、方向/类型计数。自然文字、引用、卡片文本、文字表情和解析异常不合并。来源记录数与输出条目数分别显示；合并不代表媒体已解读，需要某条上下文时按原序号展开。
- receipt：只有协调者成功串行提交后记录正式 scope_type/scope_id/period/version、expected_parent 与实际下游；候选不伪造成功回执。
- delivery：成功版本的紧凑完整 Markdown 与同源全量 HTML；无私人正文打印、上传或 Git 发布。


### 有证据的图文结合展示合同

详细 HTML 需要信息图与完整正文结合：实际日期/计划日期分开的过程时间线、self/contact 各自社会关系图、具体喜好差异和沟通/情绪/行为的场景变化图。每个节点、边或时间条目必须能对应成功 Markdown 既有结论和证据引用，图上保留 observed/inferred/unknown 状态、来源范围与时间精度；无明确变化不造曲线，不给人格、感情或关系强度打分。第三方图节点保留关系所属者/scoped reference，禁止同名/同称谓合并。

可生成本地 `visuals.json` 派生展示清单，包含标题、图类型、节点/边/时间条目、来源 Markdown 小节、evidence ID 与 ordinal_base、来源及正文 hash。它不构成新分析正文/独立 Memory，只指导渲染；正式版本成功回执核验后才允许展示，不借候选或未审核历史扩充图。原有本地图片/媒体仅在授权、稳定来源、内容实际核验后使用，不下载、不用未核实头像或猜定账号照片。没有可靠媒体时仍提供信息图和详细正文，不以无图片退化为短 Claim 列表。图表是正文的导航与解释，不能用图吞掉细节。
