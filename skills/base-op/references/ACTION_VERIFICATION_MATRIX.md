# 页面动作核验规则

本文描述接口必须满足的前后条件，不保存个人账号的运行流水或诊断结果。
页面目录是识别范围，不等同于全部动作均已验收。调用方必须检查当前操作支持状态。

| 操作 | 前置条件 | 后置条件 |
|---|---|---|
| 聊天/通讯录/发现切换 | 同进程主 HWND、已知页面、当前帧唯一导航图标 | 同一目标窗口显示目标页面 |
| 联系人选择 | 个人“联系人”分组展开、精确唯一成员行 | 唯一资料页、归档 alias 精确匹配 |
| 个人朋友圈入口 | 唯一资料窗口、稳定身份、当前帧唯一缩略图入口 | 唯一个人相册（可为右侧标签），不能以信息流替代 |
| 相册滚动 | 同一绑定窗口仍显示个人相册 | 页面仍匹配；记录有限覆盖状态 |
| 嵌入内容标签关闭 | 唯一已识别标签与当前帧叉号 | 标签消失、主窗与聊天保留 |
| 菜单退出 | 已登记菜单页面 | 菜单消失，不改变资料或草稿 |
| 辅助内容窗关闭 | 已知只读内容、非主窗 HWND | 目标辅助窗消失 |
| 图片复核导航 | 单次有效计划、窗口/帧未变、白名单操作 | 动作页面验证，联系人仍须身份核验 |

## 执行规则

- 先观察所有同进程窗口，区分主窗、编辑器、菜单、右侧嵌入内容与独立内容窗。
- 窗口句柄、PID、几何、DPI 或目标控件改变时重新观察，不执行旧坐标。
- CV/OCR 只返回当前帧坐标；所有动作由 BasicSkill 交给唯一 HWND 驱动。
- 仅幂等侧栏导航可以有界重算；发送、菜单切换、关闭和修改不盲目重试。
- 消息派发成功不等于业务成功；后置验证不足返回 success=false。
- 未知页面、重复候选、缺少稳定身份、编辑器阻断或过期确认均停止。
- 发送、表情、资料修改、点赞、评论和联网下载保持独立显式确认。

## 验收范围

新增检测器与流程应覆盖主题、DPI、窗口尺寸、内部栏宽、窗口移动、加载中、
无结果、权限限制、同名对象、辅助窗生命周期和用户中断。公共脱敏样例用于回归；
私人截图和实际运行记录留在本机，不加入 Git。不能把合成图测试视为实机认证。

接口详情见 [窗口导航](WINDOW_NAVIGATION.md)、[页面目录](UI_PAGE_CATALOG.md)
和[共用收件人规则](UI_WORKFLOW_RULES.md)。

## 定向发送与表情入口

| 操作 | 前置条件 | 后置条件 |
|---|---|---|
| 搜索选择私聊 | 当前查询 OCR 核对、同进程独立搜索弹窗 owner 对应主窗、联系人分区精确唯一项 | 当前确切聊天标题与输入区；仍须资料身份核验 |
| 搜索私聊身份 | 本地 username 与 alias 分离、当前主窗未变、当前成员头像由 CV 与精确姓名 OCR 定位 | 唯一同进程资料卡 alias 精确一致，关闭辅助窗与信息侧栏，回到同一聊天 |
| 文件传输助手 | 本地 filehelper 身份与功能分区精确唯一项 | 确切聊天标题、同主 HWND 与当前输入区 |
| 文字单次提交 | 对象和正文已确认、身份已核对、空草稿、确切草稿 OCR 一致 | 新增右侧绿色确切正文气泡、正文清空、无失败信号；仅为结果观察，非送达证明 |
| 表情面板与收藏 | 当前输入区唯一公共笑脸图标；唯一同进程原生表情弹窗 | 当前标签文字与公共心形，或当前收藏选中背板；打开标签不代表发送 |
| 历史表情发送 | 历史素材与当前唯一格须可核对，单次对象与素材确认 | 完整素材匹配与发送结果门禁仍待实现；原始格坐标不能执行 |

上述搜索/身份/文字流程为 BasicSkill 的 Python 接口，不能推定所有 MCP 入口具有同等运行时门禁。
结果未知时保留首次回执，仅增加只读复核证据，不自动重复提交。
