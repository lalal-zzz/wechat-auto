# 主模型全历史综合

此资源用于明确请求的完整历史分析。上游是固定范围内每月成功版本、独立主体/关系复核回执、真实阅读覆盖和日期明确的辅助资料；下游是会话完整 Markdown、人物/关系 Memory 与同源详细 HTML。缺月、未恢复可读正文、主体未核或成功版本哈希不符时停止可信全量交付，继续修复。

低阶阅读者可分配连续数月或一年，密集月份拆块；低阶复核者须与作者独立。主模型亲自阅读全部成功月报并完成最终综合。必要时按实际正文量形成有限时间段工作笔记，再逐段整合；不能仅阅读各代理的末尾摘要，不能把丰富月报压成几项事件。工作笔记不是第二套正式 Memory。

综合正文先按质量标准的“主题归纳与全历史变化的写作验收”及“四类主题的详细总结要求”确定每个主题要回答的用户问题，再按证据组织。生活与工作详细写阶段过程及选择；兴趣与喜好写具体对象、共同点、差异和变化；人际关系写各自与亲友同事的实际相处及影响；双方关系写建立、日常投入、转折和后续。以下是覆盖检查项，不是固定章节或十一主题模板。不要把归属纠错、核查结论或最近发现的争执当作所有主题的起笔；引用准确但没有回答主题问题的段落仍须重写。

性格/行为变化先建立最早相关证据的基线，再比较中期和最后时期的同类表现及后续持续性；无早期证据不补造，无变化不造成长。长期倾向须有跨时间独立重复行为，小事可作为模式例子，单次小事或极端事件均不自动证明性格。区分处境、短期状态、自述、承诺与实际持续改变；用事实解释归纳，不先贴标签再挑例子。

归纳后集中审核主题匹配、归纳强度、全历史时间链、同类场景比较与反例。不合格的归纳先修订并回查必要原文；来源正确或月份齐全不代替此项验收。

执行时采用一次集中审核与批量修订，重点解决主体、关键日期、关系和实际结果；已修正位置只复查变化，不对所有普通日常反复防守性复核。正文同一事实集中一次，来源局限统一末尾；未出现的维度不机械填未知段落。具体信息和跨月变化仍完整保留。

- 来源范围、全部月份版本、谁读原文/谁复核/谁综合；媒体、方向未知和辅助资料时间缺口。
- 会话场景及双方角色，关系的确立、变化、边界与仍有争议的定义。
- 重要事情的完整过程：背景、各人诉求、行动阶段、决定/变更、实际结果与开放事项；衔接有据，计划不冒充完成。
- 本人与联系人各自的具体事实、兴趣/喜恶、沟通习惯、行为/决策、情绪触发与恢复、价值观、目标及边界；保留反例、时期和场景差异，不平均成标签。
- 冲突和修复的完整回合、双方各自说法、误解与仍未解决处；不用一次道歉证明永久变化。
- 双方各自描述的亲属、朋友、同事等社会关系；speaker、actor、事实所属者、关系所属者和引用者分清。未核实第三方只用 scoped reference，不凭同名称谓合并身份。
- 约定表达、暗号、梗与语境：原句、含义成立回合、使用条件、回应、反例和变化；语言约定与行动承诺分开。
- 资料历史/朋友圈与会话对照，辅助来源的采集日期不能反推行为发生日；资料无证据时不推断心理状态。
- 精确日期清单与定义、开放任务状态、重复模式/成长变化及证据仍不足的问题。

HTML 显示综合正文及全部月度详细正文，配同源时间线、分别归属的社会关系图、具体喜好/场景对照和固定来源消息量。图形每项绑定正式版本、hash与正文依据；数量不代表关系强度。Markdown 紧凑但不删掉独立事实、重要回合与反例。二者都不能从未复核候选或旧抽样结论补齐缺失内容。
